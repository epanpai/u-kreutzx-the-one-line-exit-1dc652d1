## The entry

> I hereby resign from the library, effective immediately: after twenty years of shushing people, I have finally checked out.

123 characters, one line: a librarian's resignation whose punchline is the library's own verb — "checked out" means both leaving the job and checking a book out. Twenty years of shushing people, and the exit line is the quietest joke in the building.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 123 characters, inside the 1–140 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
